# Calorie & Macro Tracker

A single-page calorie and macronutrient logger.

- Open `index.html` in a browser to use it; no install needed.
- Food search uses the USDA FoodData Central API. Enter your own free key in the app (get one at fdc.nal.usda.gov/api-key-signup); it is stored only in your browser.
- `macro-logger.jsx` is the React component source.
